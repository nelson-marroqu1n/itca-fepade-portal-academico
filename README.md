# ITCA-FEPADE | Portal informativo académico

Sitio web estático de carácter académico que presenta información sobre la oferta educativa, las sedes y los servicios de ITCA-FEPADE. Incluye páginas informativas y promocionales para explorar carreras técnicas e ingenierías, cursos, nuevo ingreso, noticias y datos de contacto.

> Proyecto académico. Este repositorio no es el sitio oficial de ITCA-FEPADE ni está afiliado oficialmente con la institución. Algunos textos, imágenes, logotipos y documentos pertenecen a sus respectivos titulares.

## Contenido

- Página de inicio con promociones y accesos a la oferta académica.
- Catálogo de carreras técnicas e ingenierías.
- Información institucional, educación dual y sedes.
- Secciones de cursos, nuevo ingreso, noticias y contacto.
- Estilos propios en CSS e interacciones JavaScript.

## Tecnologías

- HTML5
- CSS3
- JavaScript

## Cómo verlo localmente

No requiere instalación de dependencias. Clona o descarga el repositorio y abre `Inicio.html` en un navegador.

Para servirlo localmente puedes usar la extensión **Live Server** de Visual Studio Code, abrir la carpeta del proyecto y seleccionar **Go Live**.

## Estructura

```text

```

El proyecto contiene otras páginas HTML para carreras, programas y sedes, además de una guía estudiantil en PDF.

## Publicación

Se puede publicar como sitio estático en GitHub Pages. Para que GitHub Pages encuentre la portada automáticamente, conviene renombrar `Inicio.html` a `index.html` y actualizar los enlaces internos que actualmente apuntan a `Inicio.html`.

## Nombre sugerido para el repositorio

`itca-fepade-portal-academico`
